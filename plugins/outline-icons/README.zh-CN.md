# Outline Icons

[English](README.md)

Conduit 官方文件图标主题：源码使用橙色轮廓，配置文件使用琥珀色，文档使用蓝色，文件夹使用灰蓝色。颜色适配深浅外观。

在 **设置 → 插件 → 发现 → Outline Icons → 安装** 后，到 **已安装** 选择 **使用图标**。也可以从此文件夹本地安装。停用或卸载会恢复内置图标。

插件 ID：`conduit-plugins.outline-icons`；版本：`1.0.0`；要求 Conduit `0.2.6` 或以上。插件仅包含声明式 SVG 数据，不执行脚本。

许可证：未声明。仓库目前没有项目级许可证，此插件也尚未单独声明再分发许可。
