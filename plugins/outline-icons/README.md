# Outline Icons

[简体中文](README.zh-CN.md)

An official file icon theme for Conduit. Source files use orange outlines, configuration files use amber, documents use blue, and folders use slate. Colors adapt to light and dark appearance.

Install from **Settings → Plugins → Discover → Outline Icons → Install**, then choose **Use icons** in **Installed**. The package is also installable from this folder. Disabling or uninstalling it restores the built-in icons.

Plugin ID: `conduit-plugins.outline-icons`. Version: `1.0.0`. Requires Conduit `0.2.6` or newer. This package contains declarative SVG data and no executable scripts.
