# README screenshots

Native Conduit 0.3.15 on Windows, captured on 2026-11-23 in dark mode with an English interface and fictional Chinese Orbit project content. These are application screenshots, not HTML prototypes or generated UI mockups.

| File | Content | Size |
| --- | --- | --- |
| `workspace.png` | Project conversations, chat, and reference code | 1664 × 1031 |
| `git-review.png` | Staged changes, side-by-side Diff, and reference code | 1664 × 1031 |
| `usage-insights.png` | Daily trends, period comparison, and model rankings | 1664 × 1031 |

Projects, conversations, tool records, and usage values are synthetic. They illustrate the interface and do not represent real model execution, performance, prices, or subscription quotas. No model account was used to create the demo data.

The workspace image was captured from the isolated demo window; the Git and usage images were captured by the project maintainer from the same demo. Files are lossless PNGs. The workspace capture was cropped to remove the desktop outside the window; the supplied Git and usage images were converted from BMP without resizing or altering their content. Both project READMEs use these same assets.

To regenerate the isolated data and launch a local build, follow the [screenshot demo guide](../../examples/screenshot-demo/README.md). Use `--fresh` for the current synthetic usage records. Keep the window size and theme consistent, and capture the application window after dismissing tooltips or menus.

These repository assets follow the project license. Temporary captures and processing logs belong under ignored `target/`, not in this directory.
