# Conduit v0.3.22

长对话阅读时随时查看当前问题，模型与服务配置在重启后保留，并改善主题辨识度和设置页面。

## 更新亮点

- 聊天顶部显示当前阅读位置对应的用户消息，点击即可回到原文。
- 保存已导入的 cc-switch 服务配置和 CLI 模型目录，重启后继续使用，读取失败也不会清空缓存。
- 吸顶条与会话标签栏通过圆弧衔接，深浅主题下使用一致的顶部底色；文本选区和自定义工作空间颜色更清晰。

## 新增

- 长对话增加用户消息吸顶条：原文滚出顶部后显示单行摘要，跨轮次滚动时自动切换；支持点击跳转、在吸顶条上滚动，以及分屏独立定位。

## 改进

- 精简设置页重复说明，调整外观、会话和扩展等页面的布局，让常用配置更容易查找。
- 模型与服务优先使用已保存的目录和运行配置，通过重新读取配置主动同步外部变更，保留已获取的服务模型目录。

## 修复

- 修复配套深浅主题中文本选区不易辨认的问题，提高选区背景与文字的对比度。
- 修复配套主题覆盖手动设置的工作空间颜色的问题，侧栏标识与会话标签圆弧描边使用同一自定义颜色。
