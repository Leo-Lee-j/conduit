# Conduit v0.3.21

本次更新接入 Gemini CLI，完善任务进度与会话整理，并改进主题、用量统计和 Git 操作提示。

## 更新亮点

- 新增 Gemini CLI，可在同一工作区使用流式对话、模型选择、工具审批和会话续接。
- 任务列表同步 CLI 原生计划与 Claude Tasks，支持查看完成进度、负责人和前置依赖，并在重启后恢复。
- 新增每日自动归档与工作区图钉快捷操作，方便整理长期未使用的会话和常用项目。
- 新增三组配套的浅色与深色主题，优化侧栏选中状态及工作区自定义颜色显示。
- 用量统计支持分页和横向滚动，减少翻页、滚动时的重复计算；历史会话恢复上下文与 Token 用量显示。

## 新增

- 支持 Gemini CLI 原生连接。在 CLI 设置中启用后，可使用原生认证、流式回复、工具审批、停止和续接会话；模型列表随连接加载。首次使用前需在终端完成 Gemini CLI 认证。
- 输入框上方与会话数据面板同步展示 CLI 任务列表。Claude Tasks 保留原生任务编号、负责人和依赖关系，支持跨轮次保存与历史恢复；普通计划按当前对话轮次展示。
- 会话设置增加自动归档开关与闲置时间设置，按每日检查整理符合条件的会话。
- 增加石墨与靛蓝、暖纸与赤陶、岩灰与青绿三组主题及对应深色版本，可分别选择浅色和深色配色。

## 改进

- 用量统计的调用记录、提供商和模型列表改为分页表格，提供每页条数、首页与末页操作，支持横向滚动查看完整列；筛选变化时重置页码，数据更新后刷新汇总。
- 思考强度选项按当前模型与引擎能力展示，优先使用原生模型目录；切换模型时清除旧选择，无法确认的模型跟随默认设置。
- 调整 AI 设置的导航、引擎切换和模型选择控件，精简重复说明，并保留服务不可用、模型待确认等必要提示。
- 点击工作区图钉可直接取消置顶；侧栏使用渐隐背景展示悬停与选中状态，自定义工作区颜色在各主题中保持可辨识。
- Git 分支菜单为不可执行的操作显示锁定状态和具体原因，说明任务占用、Worktree 占用、缺少上游或远程仓库等情况。
- 减少代码高亮、长对话正文和图形渲染的内存占用，并简化会话数据面板的文件变更标记。

## 修复

- 修复从 CLI 历史恢复会话后上下文占用与 Token 用量缺失的问题。
- 修复 AI 设置中的引擎切换栏未充分使用可用宽度的问题。
