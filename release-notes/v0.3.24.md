# Conduit v0.3.24

设置改为独立工作视图，聊天新增常用命令与扩展查看小窗，Git 操作增加可停止的进度提示，并改善文件浏览与模型列表刷新体验。

## 更新亮点

- 设置独立展示，统一搜索、分类和返回入口；关闭后恢复工作台面板、宽度与输入焦点。
- 外观按主题、界面、聊天、代码和背景分组，支持仅查看已修改属性、按组恢复默认及按需展开实时预览。
- 输入 `/` 即可使用停止回复、重命名、置顶等通用命令；`/skill` 和 `/mcp` 可快速搜索、刷新当前引擎与工作区的扩展配置。
- Git 操作在底部显示进度和停止入口；会话在一个分支运行时，可继续操作不受影响的其他分支。
- HTML 预览可直接在默认浏览器打开；子代理历史刷新保留已显示内容，模型配置缺少定义时保留已有列表。

## 新增

- 所有引擎均可使用 `/help`、`/stop`、`/rename`、`/pin`、`/unpin`、`/new` 和 `/settings`。分屏中的操作作用于发起命令的会话；停止回复同时暂停该会话的排队消息。
- 新增 Skill / MCP 配置查看小窗，展示本地发现的名称、说明、来源与禁用状态，支持搜索和刷新。MCP 仅展示配置，不自动连接；不支持本地发现的引擎会提示使用原生管理入口。
- HTML 源码预览增加浏览器入口，即使系统将 HTML 文件关联到编辑器，也能通过默认浏览器查看磁盘上的原始页面，并保留相对资源路径。
- Git 操作在底部状态栏显示操作名称、进度横条和停止按钮，切换工作区后仍可停止原操作。停止请求会等待后台命令退出和必要清理完成，已完成的提交或推送按实际结果处理。

## 改进

- 统一设置页面与编辑弹窗的输入、选择和数字控件，采用紧凑分组、列表与详情布局；窄窗口保留完整分类入口，宽窗口限制表单宽度，便于浏览和编辑。
- 外观搜索支持中文名称与配置字段名；增加分组和“仅已修改”筛选，按组恢复默认互不影响，背景恢复保留下载历史。工作区自动排序与非活跃折叠统一移至“通用 → 工作区行为”。
- 快捷键按命令、绑定和作用范围展示；模型、服务、引擎及扩展页面统一操作布局，并明确区分 MCP 配置启用、连接检测和会话加载状态。
- 命令菜单在无匹配项时仍显示连接与刷新入口，修改搜索词后选中新的匹配项；帮助、停止、重命名、置顶和扩展查看操作保留附件。
- 子代理输入区采用与主聊天一致的布局、字号和焦点样式，继续保留独立草稿与键盘操作。用量表格充分利用可用宽度。
- 缩短选中文件提交和冲突解决占用 Git 索引锁的时间；遇到短暂锁冲突时有限等待或重试，持续占用时给出具体锁文件提示。

## 修复

- 修复会话在分支 A 运行时，无关分支 B 的更新、重命名和推送等操作也被阻止的问题；仍保护会影响运行会话的分支与工作树操作。
- 修复 Claude、Codex 配置刷新后缺少模型定义时，已有模型列表被意外清空的问题。
- 修复子代理历史尚未加载时缺少明确状态、刷新时已加载内容消失的问题。
- 修复 Windows 文件资源管理器定位文件不可靠的问题。
- 会话数据面板排除被 Git 忽略的文件，兼容工作区短路径和目录别名；限制卡片内容高度并允许滚动，避免长列表挤占操作区域。
