# 设置与 AI 连接

设置作为工作区标签页打开，与聊天和文件共用主区标签栏，保留左侧工作区与右侧详情面板及其宽度。搜索、分类导航、返回工作台、焦点与未保存表单共同组成设置工作区；快捷键见[使用指南](usage.md)。

## 应用语言

在 **通用 → 语言 → 应用语言** 中选择 **English** 或 **简体中文**。切换立即生效并自动保存，不清空草稿、表单、排队消息或运行任务。新安装默认英文；旧配置没有语言字段时继续使用中文，未知语言标识回退英文。界面、聊天与代码字体独立设置，不随语言切换重置。

应用只翻译自身界面文字。用户内容、模型回复、终端输出、路径和自定义提示词保持原样。扩展语言的步骤见[国际化指南](internationalization.md)。

## 信息与保存方式

| 页面 | 管理内容 | 保存边界 |
| --- | --- | --- |
| AI 引擎 | 启停、实际启动路径、版本与更新 | 路径和开关自动保存；认证仍由 CLI 完成 |
| 模型与服务 | 本地服务、CCS 来源、原生目录、自定义模型和隐藏项 | 偏好自动保存；服务表单明确保存/取消 |
| 新会话默认 | 各引擎的默认服务与模型 | 不改写已有会话；输入区临时选择优先 |
| Skills | 引擎/范围、搜索、创建、导入、编辑、停用/恢复 | 修改实际来源文件，不复制为会话能力快照 |
| MCP 服务 | 定义、启停、来源编辑与连接检测 | 预览原生配置修改后保存；检测与配置状态分离 |

底部区分自动保存中、失败、表单保存和只读。存在未保存表单时，Esc、取消或关闭先确认继续编辑/放弃；检测或保存进行中不能丢弃。引擎、范围或页面变化使旧后台结果失效，不能把其他来源的结果写入当前页。

## 引擎与模型

`EngineDescriptor` 集中稳定身份、名称、路径探测、版本识别、能力和适配器工厂。`Provider` 保留既有序列化值；引擎配置映射兼容旧路径字段。新增引擎的完整要求见[CLI 适配器](cli-adapters.md)。

停用仅阻止后续聊天、队列、命名和 Git 说明任务启动，保留在途任务与历史。没有可用引擎时明确提示，不静默切换。

模型目录与应用偏好分开：按 ID 合并原生项和本地定义，保存显示名称、备注、上下文窗口及隐藏状态；刷新不清除偏好。隐藏不改写历史，已选和默认模型仍可识别。不同服务的同名模型不能跨服务合并。服务被现有会话、辅助任务或默认配置引用时不能直接删除。

本地 API Key 通过当前 Windows 账户加密保存，也可只保存环境变量名。子进程仅接收其所需的路由与凭据；日志、错误、模型目录和普通状态展示不应泄露认证头、URL 敏感参数或命令行密钥。CCS 来源在 cc-switch 中编辑。

Qoder CLI 使用原生认证和模型配置，不提供 Conduit 自定义 Provider / CCS 路由。会话连接后加载模型及思考档位，首次可使用 CLI 默认值。

## CLI 检查与安装更新

一个按钮依次显示“检查更新”“一键更新”或短暂的“已经是最新版本”，状态按引擎与实际启动路径隔离。后台读取本机 `--version`，查询官方稳定版本；网络失败保留已读本机版本。检查可以取消，只读模式仍可检查。

安装前重新核对本机与目标版本；完成后再次检测原路径，只有达到目标才显示成功。只凭安装器退出码为零不能认定已经更新。

- npm 安装通过启动器和相邻包信息识别原 prefix，在原安装位置更新到目标精确版本，保留空格、中文及特殊字符参数。
- 原生 Claude 使用所选程序的 `update`，原生 OpenCode 使用 `upgrade <目标版本>`。
- Qoder 从官方 npm 元数据检查版本；可识别的 npm 安装按原 prefix 更新，独立安装提供原生更新说明。
- 独立 Codex 或无法可靠识别的启动器，以及 WinGet、Scoop、Chocolatey、pnpm、Yarn、Bun 来源提供原渠道说明，避免另装副本。
- 更新要求可写实例，并与会话、命名、提交说明、模型查询及其他安装互斥。安装最长 10 分钟；可停止，取消后提示安装可能未完成，不显示成功。
- 输出仅保留有界尾部，进程通过 Job 管理；完成后使扩展及 OpenCode 模型缓存失效。

应用自身的签名更新与 CLI 更新是两套流程，见[发布与更新](releasing.md)。

## Skills 与 MCP

目录按引擎、实际 CLI 路径及工作区区分。同名不同来源分别保留；“已发现”“未禁用”和连接成功都不等于当前会话已加载。原生 CLI 决定最终配置优先级和权限，辅助任务的工具限制也不与普通对话混用。

Qoder 的 Skills/MCP 暂由原生 CLI 管理，应用内创建与导入入口禁用。

普通聊天的只读、工作区内修改和完全访问三个权限等级均放行原生 CLI 已加载的 MCP 工具，不额外弹出工具执行审批，也不清空 MCP 配置。MCP 服务的启停、认证和原生加载规则继续生效；命名、提交说明等纯文本辅助任务仍禁用工具。

Skill 导入保留脚本和资源，不覆盖同名目录。停用通过 `SKILL.md` 与 `SKILL.md.conduit-disabled` 改名实现；共享目录影响所有使用它的 CLI，插件托管内容不直接修改。

MCP 保存先预览合并，保留其他配置与注释，校验外部修改冲突并保留 `.conduit-backup`。Codex / OpenCode 的启停修改原生 `enabled`；Claude 和插件托管来源遵循各自原生管理方式。

进入 MCP 页自动按队列检测一次未禁用服务，也可手动重测；离页或切换上下文取消旧检测。检测会启动配置命令或连接远程端点，初始化并读取工具列表，不调用工具。支持 stdio 和 Streamable HTTP；OAuth、旧式 SSE 及动态配置展开由原生 CLI 处理。检测能力与未覆盖范围应在界面说明，不能用配置扫描推定可用工具。

## 外观与布局

“外观 → 背景图”可浏览 Wallhaven 的安全内容壁纸，无需账户或 API Key。启用使用独立开关；点击“浏览 Wallhaven”，在背景强度下方展开搜索区。可选关键词、分类、排序和颜色；“只看纯色背景”按站点 solid color 标签筛选，可能包含图案。点击“搜索 / 换一批”或按 Enter，再用卡片的“应用背景”按钮应用；卡片显示应用中／已应用状态，随机模式再次搜索会换一批结果。可调整背景强度、关闭显示或收起浏览区。壁纸下载完成后才替换当前背景，失败保留上一张；已选图片缓存在本地，启动时无需联网。为限制内存，单张最多 20 MiB、16 Mi 像素，显示纹理最多 4K。设计和性能边界见[应用背景图](background-images.md)。

“外观 → 应用界面 → 自动折叠非活跃工作空间”默认关闭。开启后，最近 72 小时内没有会话活动的工作空间会自动折叠；按会话最后活动时间判断，包含尚未加载的历史会话。当前工作空间、正在运行的会话和搜索结果不会被自动折叠。手动展开在本次运行中保留，关闭开关后自动折叠解除，手动折叠保持不变。

界面字体和字号与聊天正文、输入框、代码、终端分别管理。界面字号基准 16 px，可调 12–20 px；旧配置使用默认值，越界值加载时收敛，缺失字体回退。界面“恢复默认”只恢复界面字体和字号。

管理页复用页头、引擎切换和状态标签；按主区实际可用宽度换行，短窗口压缩说明而保留列表与操作。搜索可定位具体分组，“查看完整页面”恢复整页。

主要实现位于 [settings/](../src/app/settings/)、[engines.rs](../src/engines.rs)、[cli/updates/](../src/cli/updates/)、[extensions/](../src/extensions/)。回归包括只读、凭据、未保存离开、过期结果、原路径更新和明暗主题窄窗布局，见[测试与验收](testing.md)。
