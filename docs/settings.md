# 设置与 AI 工作流

设置作为工作区标签页打开，与聊天和文件共用主区标签栏，保留左侧工作区与右侧详情面板及其宽度。搜索、分类导航、返回工作台、焦点与未保存表单共同组成设置工作区；快捷键见[使用指南](usage.md)。

## 设置分类与生效范围

设置导航按四类组织：

- **工作台**：通用、外观与字体、快捷键。
- **AI 与工作流**：AI 引擎、模型与服务、会话设置、Git 工作流。
- **扩展能力**：Skills、MCP 服务、插件。
- **应用维护**：数据与更新。

按设置主区的实际宽度和界面字号切换布局：空间充足时显示文字导航；空间不足时使用带完整分类文字的下拉入口，搜索与返回仍可用，不强制隐藏工作台周围的面板。只读模式禁止写配置，仍可浏览分类、切换当前查看的引擎和搜索。

**会话设置**分为四区，各自说明生效范围：新会话默认服务与模型、默认权限、聊天显示、自动命名。前两区不追改已有会话；聊天显示偏好立即影响现有聊天。自动命名的首轮策略在第一个完成轮次触发，最新轮次策略可在已有会话后续完成轮次更新标题，但不会批量重命名历史；关闭自动命名只取消自动任务，手动 AI 重命名仍可用。

原自动命名内部入口仍兼容；旧搜索词会进入新的会话分区。内部路由身份保留，不迁移配置或重写历史。详细设计与验收说明见[原生设置 UI 接入](design/settings-ui-native.md)。

## 消息通知

通用 → 消息通知 → 使用系统通知默认关闭。开启后改用 Windows 系统通知，不再显示应用内弹窗；系统通知不可用时自动回退到应用内通知，通知历史、未读状态和来源导航保持不变。

## 应用语言

在 **通用 → 语言 → 应用语言** 中选择 **English** 或 **简体中文**。切换立即生效并自动保存，不清空草稿、表单、排队消息或运行任务。新安装默认英文；旧配置没有语言字段时继续使用中文，未知语言标识回退英文。界面、聊天与代码字体独立设置，不随语言切换重置。

应用只翻译自身界面文字。用户内容、模型回复、终端输出、路径和自定义提示词保持原样。扩展语言的步骤见[国际化指南](internationalization.md)。

## 信息与保存方式

在 **外观与字体 → 外观** 中选择跟随系统、浅色或深色模式，并分别配置浅色与深色主题。内置 Conduit 和 GPUI Kit 的 Ayu、Catppuccin、Everforest、Gruvbox、Solarized、Tokyo Night 等主题，可在下拉列表中搜索名称并查看配色色块。选择立即应用并自动保存；跟随系统时使用对应明暗主题。侧栏、聊天、菜单、输入框与代码高亮同步切换，界面和代码字体保持独立设置。旧配置继续使用 Conduit，无法识别或明暗类型不符的主题回退到对应 Conduit 配色。

| 页面 | 管理内容 | 保存边界 |
| --- | --- | --- |
| AI 引擎 | 启停、实际启动路径、版本与更新 | 路径和开关自动保存；认证仍由 CLI 完成 |
| 模型与服务 | 本地服务、CCS 来源、原生目录、自定义模型和隐藏项 | 偏好自动保存；服务表单明确保存/取消 |
| 会话设置 → 新会话默认 | 各引擎的默认服务与模型 | 不改写已有会话；输入区临时选择优先 |
| Skills | 已安装与发现、引擎/范围、搜索、在线安装、本地导入、编辑、停用/恢复 | 修改实际来源文件；在线安装保留完整目录，不覆盖同名目录 |
| MCP 服务 | 已安装与发现、在线添加、定义、启停、来源编辑与连接检测 | 预览原生配置修改后保存；检测与配置状态分离 |

底部区分自动保存中、失败、表单保存和只读。存在未保存表单时，Esc、取消或关闭先确认继续编辑/放弃；检测或保存进行中不能丢弃。与引擎或工作区绑定的检测在上下文或页面变化后丢弃过期回执，不能把其他来源的结果写入当前页；全局模型目录读取独立，不因浏览分类统一取消。

## 引擎与模型

`EngineDescriptor` 集中稳定身份、名称、路径探测、版本识别、能力和适配器工厂。`Provider` 保留既有序列化值；引擎配置映射兼容旧路径字段。新增引擎的完整要求见[CLI 适配器](cli-adapters.md)。

停用仅阻止后续聊天、队列、命名和 Git 说明任务启动，保留在途任务与历史。没有可用引擎时明确提示，不静默切换。

“模型与服务”顶部显示当前引擎的新会话默认服务及模型，下方按 cc-switch 与本地配置分组显示服务列表。宽窗口中，点击服务在右侧页内查看模型和关联会话；窄窗口进入页内详情，通过“返回服务列表”继续选择。查看服务不会改变默认配置，只有明确点击“设为新会话默认”才会切换。会话数量只统计会话，默认配置、自动命名和 Git 提交说明等用途单独列出。服务级“设为新会话默认”跟随服务的默认模型，也可在模型详情中指定模型；与“会话设置 → 新会话默认”共用同一份配置，不改变已有会话。原生模型目录和配置来源保留独立入口，搜索结果仍能定位原有分组。

本地服务在详情中编辑或删除，删除前再次核对引用和只读状态。cc-switch 服务可打开已注册的 cc-switch 应用，再在其中选择服务进行编辑；返回后使用“重新读取配置”同步。未注册或无法启动时提示手动打开，不改写外部配置。

模型目录与应用偏好分开：按 ID 合并原生项和本地定义，保存显示名称、备注、上下文窗口及隐藏状态；刷新不清除偏好。隐藏不改写历史，已选和默认模型仍可识别。不同服务的同名模型不能跨服务合并。服务被现有会话、辅助任务或默认配置引用时不能直接删除。编辑共享服务的端点、凭据或模型配置会影响引用它的已有会话后续使用，因此编辑表单明确显示共享配置范围；保存沿用既有表单和未保存保护，不创建服务新版本，也不批量改写历史。已保存但无法在当前目录确认的默认模型 ID 保留并提示待确认，不以目录未加载推定模型不可用。

本地 API Key 通过当前 Windows 账户加密保存，也可只保存环境变量名。子进程仅接收其所需的路由与凭据；日志、错误、模型目录和普通状态展示不应泄露认证头、URL 敏感参数或命令行密钥。CCS 来源在 cc-switch 中编辑。

## CLI 检查与安装更新

一个按钮依次显示“检查更新”“一键更新”或短暂的“已经是最新版本”，状态按引擎与实际启动路径隔离。后台读取本机 `--version`，查询官方稳定版本；网络失败保留已读本机版本。检查可以取消，只读模式仍可检查。

安装前重新核对本机与目标版本；完成后再次检测原路径，只有达到目标才显示成功。只凭安装器退出码为零不能认定已经更新。

- npm 安装通过启动器和相邻包信息识别原 prefix，在原安装位置更新到目标精确版本，保留空格、中文及特殊字符参数。
- 原生 Claude 使用所选程序的 `update`，原生 OpenCode 使用 `upgrade <目标版本>`。
- Qoder 从官方 npm 元数据检查版本；可识别的 npm 安装按原 prefix 更新，独立安装提供原生更新说明。
- 独立 Codex 或无法可靠识别的启动器，以及 WinGet、Scoop、Chocolatey、pnpm、Yarn、Bun 来源提供原渠道说明，避免另装副本。
- 更新要求可写实例，并与会话、命名、提交说明、模型查询及其他安装互斥。安装最长 10 分钟；可停止，取消后提示安装可能未完成，不显示成功。
- 输出仅保留有界尾部，进程通过 Job 管理；完成后使扩展及 OpenCode 模型缓存失效。

应用自身的签名更新与 CLI 更新是两套流程，见[发布与更新](releasing.md)。

## Skills 与 MCP

目录按引擎、实际 CLI 路径及工作区区分。同名不同来源分别保留；“已发现”“未禁用”和连接成功都不等于当前会话已加载。原生 CLI 决定最终配置优先级和权限，辅助任务的工具限制也不与普通对话混用。

Qoder 的 Skills/MCP 暂由原生 CLI 管理，应用内创建与导入入口禁用。

普通聊天的只读、工作区内修改和完全访问三个权限等级均放行原生 CLI 已加载的 MCP 工具，不额外弹出工具执行审批，也不清空 MCP 配置。MCP 服务的启停、认证和原生加载规则继续生效；命名、提交说明等纯文本辅助任务仍禁用工具。

自动任务使用独立的只读执行策略：保留项目文件读取能力，禁用 MCP 工具，并禁止运行中提升权限。策略只作用于自动执行的轮次；之后在结果会话中手动发送消息时，使用普通聊天的权限规则。

Skill 导入保留脚本和资源，不覆盖同名目录。停用通过 `SKILL.md` 与 `SKILL.md.conduit-disabled` 改名实现；共享目录影响所有使用它的 CLI，插件托管内容不直接修改。

进入 MCP 页自动按队列检测一次未禁用服务，也可手动重测；通过“发现”添加的服务始终由用户手动验证，不参与设置页的自动检测。离页或切换上下文取消旧检测。检测会启动配置命令或连接远程端点，初始化并读取工具列表，不调用工具。支持 stdio 和 Streamable HTTP；OAuth、旧式 SSE 及动态配置展开由原生 CLI 处理。检测能力与未覆盖范围应在界面说明，不能用配置扫描推定可用工具。

### 在线发现与安装

在 Skills 或 MCP 服务页切换到“发现”，先选择目标引擎和全局/工作区范围。安装详情固定显示该目标；保存完成后刷新本地列表，发现卡片的“已安装/已添加”按目标范围区分。Qoder 与只读实例可浏览，但不能写入。

- **Skills**：精选目录提供常用公开仓库；切换到 skills.sh 可搜索第三方 Skill；GitHub 来源支持 `owner/repo`、仓库首页 URL，以及 `owner/repo@ref#directory`（例如 `vercel-labs/agent-skills@main#skills/react-best-practices`）。默认解析仓库 HEAD，并在详情中固定到完整 commit。详情展示说明、真实目录、文件数量及大小；安装会下载该 Skill 目录的脚本与资源，不执行其中的脚本。
- **MCP**：从官方 MCP Registry 搜索并分页加载。详情提供受支持的远程 Streamable HTTP 或 npm stdio 方案，填写服务名称、URL 变量、参数、环境变量及请求头，先预览再保存。密钥输入与预览遮罩，实际值只写入所选引擎的原生配置；安装回执不保存这些值。
- **运行时**：npm 方案要求本机已有 Node/npx，并固定包版本。添加只保存启动配置；首次手动验证或 CLI 启动时，npx 才可能下载并运行包。保存成功不表示连接或认证成功。
- **缓存与失败**：目录缓存 15 分钟，可主动刷新；网络异常时有缓存则回退并标明时间。搜索和 Skill 下载可取消，旧请求不能覆盖新搜索。Skill 下载使用暂存目录，失败清理临时文件；拒绝路径越界、链接、大小写冲突及同名覆盖。单个 Skill 最多 2,000 个目录项、20 MiB。

首版仅接入公开 GitHub 内容、skills.sh 搜索和直接访问的 MCP Registry（带本地缓存）；尚无生产目录聚合服务。暂不支持私有仓库、在线更新/卸载、被 GitHub 截断的大型仓库树、PyPI/OCI/MCPB 安装、OAuth 登录或自定义包运行时。skills.sh 使用其 CLI 当前使用的匿名搜索接口，来源不可用时可改用 GitHub。

## 外观与布局

“外观与字体 → 外观 → 自动折叠非活跃工作空间”默认关闭。开启后，最近 72 小时内没有会话活动的工作空间会自动折叠；按会话最后活动时间判断，包含尚未加载的历史会话。当前工作空间、正在运行的会话和搜索结果不会被自动折叠。手动展开在本次运行中保留，关闭开关后自动折叠解除，手动折叠保持不变。

界面字体和字号与聊天正文、输入框、代码、终端分别管理。界面字号基准 16 px，可调 12–20 px；旧配置使用默认值，越界值加载时收敛，缺失字体回退。界面“恢复默认”只恢复界面字体和字号。

管理页复用页头、引擎切换和状态标签；按主区实际可用宽度换行，短窗口压缩说明而保留列表与操作。搜索可定位具体分组，“查看完整页面”恢复整页。

主要实现位于 [settings/](../src/app/settings/)、[engines.rs](../src/engines.rs)、[cli/updates/](../src/cli/updates/)、[extensions/](../src/extensions/)。回归包括只读、凭据、未保存离开、过期结果、原路径更新和明暗主题窄窗布局，见[测试与验收](testing.md)。
