缓存默认最多 32 个实例，按 `(owner, view, scope)` 区分，跨 owner 共用预算。可见实例不淘汰，隐藏实例按最近使用顺序淘汰；全被可见实例占用时拒绝新建，不突破预算。隐藏只释放在途任务，保留轻量状态；作用域删除、owner 撤销、停止或关闭会释放任务及实例状态。当前示例是首个消费者；核心文件 / Git / 工具详情继续保留其原生业务状态，未把整套应用业务改写成插件。

每次创建实例取得新的单调 generation。请求持有私有的 `ViewRequest`、实例 generation、contextVersion、完整 ViewInstanceKey 及一次性取消身份；一个实例最多持有一个在途资源。新请求替换旧请求，隐藏 / 上下文切换取消旧请求，缓存移除会先设置取消标记再释放任务。结果发布前重新同步宿主上下文，验证注册身份、代次、路由版本、scope、条件、可写 / 关闭状态、实例可见性与当前请求身份；已消费的结果不能二次发布。

同名 owner 注销后重新注册不会继承旧实体、任务或 renderer / command / status 绑定。撤销注册立即使请求校验失败，随后宿主同步清理缓存及原生绑定；即使重新绑定发生在两次渲染之间，也会清除旧代次状态。宿主只读查询可以重新发起，但切换只读之前的结果仍失效；外部 owner 的实例在只读时被移除。

## 摘要与刷新边界

摘要只保存普通 Rust 数值、字符串和数组，可在线程间传递；GPUI Entity、ScrollHandle、Task 和 WeakEntity 留在 app 适配器。路径显示最多 4096 字节，名称和每个会话标题最多 256 字节，均在 UTF-8 边界截断并移除控制字符。

初次打开立即显示当前摘要；后续变化以 50ms 的可取消任务合并，只保留最新有界快照。完成时还比较宿主当前元数据，防止同一 contextVersion 下的旧摘要覆盖新内容。相同摘要不通知视图，也不调用全应用 `notify`。隐藏视图停止摘要刷新，重新打开时重新核对。上下文和命令资格独立更新；摘要变化不会推进路由 contextVersion。

两侧概览都使用 GPUI 缓存绘制。测试向聊天正文连续追加五次增量，确认左右概览和导航容器 render 次数不增加；连续三次重命名只产生一次摘要发布。元数据变化导致子视图通知时，框架可以重绘其父容器，这不属于聊天 token 导致的无关刷新。

当前宿主仍在通知 / 渲染时比较选中工作区的元数据，并统计会话数、归档数与运行数；没有宣称该扫描是 O(1)，也没有完成生产性能基准。没有为外部插件定义最终摘要订阅协议或能力授权 API。
