# 原生贡献契约

注册层由 [plugins.rs](../../src/plugins.rs)导出，数据类型位于 [plugins/](../../src/plugins/)，桌面接入在 [app/plugin_ui/](../../src/app/plugin_ui/)。注册层不依赖 `ConduitApp`；宿主 renderer map 持有原生实体，贡献只保存可验证的描述与 key。

## 身份与注册

| 类型 | 责任 |
| --- | --- |
| `ContributionSet` | 一个 owner 的命令、视图、活动项和状态项，完整校验后原子注册 |
| `ViewDescriptor` | 稳定 ID、标题、navigation/right 位置、scope、renderer 和显示条件 |
| `ActivityItem` | 排序、图标及打开视图/执行命令动作 |
| `StatusItem` | 左右对齐、优先级、文本/图标/提示及可选命令 |
| `CommandDescriptor` | 参数策略、权限及同 owner 的处理目标 |
| `CommandInvocation` | 用户动作时捕获的命令、参数、来源和上下文版本 |
| `ViewInstanceKey` | owner、view 和作用域身份 |
| `ScopeKey` | Global / Workspace / Session；Session 同时绑定工作区和会话 |

内置 ID 使用保留的 `conduit.*` 命名空间，通过宿主专属身份注册。外部清单不能只靠相同字符串取得内置权限。ID、renderer、图标、位置、作用域与所有引用在注册前检查，失败不留部分贡献。

活动入口直接打开同 owner 的 navigation 视图；打开右侧通过命令。状态项也只引用同 owner 命令，不提供任意跨插件调用。注销先拒绝新命令，再撤销贡献和实例；失去当前选择时按宿主规则回退。

`when` 只接受省略、单键、`!key` 或 `&&` 组合，固定键为 `workspace.open`、`session.selected`、`session.running`、`document.open`、`host.writable`。它只决定可见性，不能代替执行时的权限和业务校验。

## 布局与原生能力

活动项按 order / ID 保持确定顺序；状态项按 priority / ID 选择保留次序。空间不足使用溢出入口，不遮挡宿主关键操作。设置与关于等宿主入口保留各自位置。

导航与右侧容器只管理显示、选择、宽度和焦点，不理解工具输入/输出、Git 或通知内容。工具选择和滚动按会话隔离；工作区文件、Diff 和 Git 状态仍由原模块持有。

同一功能支持键盘、鼠标和菜单路径。未读/后台事件不会自动替换当前视图或抢焦点；点击用户动作后才导航。失效、隐藏或注销的视图不得被迟到结果重新挂载。

## 上下文、缓存与异步

上下文版本绑定工作区、会话、文档、只读及关闭状态。命令在点击时捕获目标，完成时不能重新使用“当前会话”推测原目标；摘要变化可以刷新可见视图，但不必无条件增加上下文版本。

实例缓存有界，按稳定 `ViewInstanceKey` 复用。隐藏与销毁区分：隐藏可保留合法状态，但旧任务不能因为结果回来而重新变为可见。

`RequestTicket` 与实例代次、owner 和上下文共同约束异步结果。接收时再次核对当前注册身份、可见性、scope 和票据；重新注册但数字版本相同仍是不同注册表身份。停止/注销使保存的命令和结果失效。

宿主在实际处理前复核业务限制，包括只读、Git/CLI 互斥和目标存在性。缓存或贡献描述不能赋予绕过这些检查的路径。

## 生命周期与验收

停止、窗口销毁和更新准备清理 owner 实例、票据与缓存；外部运行时还需清理 VM、任务与浮层，见[Shell 运行时](runtime.md)。轻量摘要可独立刷新，不能为显示状态启动模型调用。
