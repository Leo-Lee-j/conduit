底栏先为核心控件分配空间，再测量贡献区域的实际宽度。窗口、导航宽度或右侧停靠变化后，在下一帧重新分配可见项；区域有裁剪保护。保留项为全局优先级前缀，不用较短的低优先级项挤掉高优先级项；更多按钮预留 28px 加间距，容不下任何完整贡献时仍可进入菜单。左右对齐只影响所保留项的位置，不改变保留次序。

动态值与声明分开：原生 provider 按宿主 scope 读取当前元数据，不改写注册表、不增加 registry revision。文字 / tooltip 分别限制为 256 / 1024 字节，按 UTF-8 字符边界截取并移除控制字符；宿主组合 tooltip 时保留完整有界文字及说明。没有处理器的命令仍显示为禁用，不静默执行其他命令。

每个原生命令绑定持有对应 Registration。点击保存 CommandInvocation；执行前同步宿主上下文，并重新验证 owner、注册代次、contextVersion、scope、参数、capability、writable 和 closing。只读时允许显式声明为查询的宿主命令，禁止宿主写操作及全部外部命令；撤销后重新注册不会恢复旧请求或自动继承旧命令绑定。视图发起命令还需使用相同 owner 的注册句柄。

示例仅访问工作区路径和会话标题、数量、归档与运行状态，不读取或加载聊天正文。两个视图独立使用 `(owner, view, workspace)` 滚动状态，重复点击和关闭 / 再打开保留状态，切换工作区隔离状态；示例缓存最多 32 项，可见项不淘汰，测试覆盖隐藏作用域淘汰。注销 owner 或删除工作区时清理对应示例状态。

## 开发开关

默认功能集合不注册示例。显式启用：

```powershell
$env:CONDUIT_DATA_DIR = Join-Path (Get-Location).Path 'target/plugin-example-data'
cargo run --locked --features plugin-example
```

打开任意工作区后，可从左侧“工作区概览”进入导航页，点击“在右侧查看摘要”，或点击底栏“概览 · N 个会话”（窄窗口时在“更多状态”菜单中）。右侧关闭后再次点击底栏按钮恢复原摘要状态。此开关只增加随应用编译的原生示例，不提供外部插件安装或脚本执行能力。
