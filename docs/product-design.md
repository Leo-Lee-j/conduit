# 产品范围

Conduit 是按本地工作区组织 AI 编程任务的 Windows 桌面工作台。它统一对话、历史、工具执行状态和 Git 操作，复用 Claude Code、Codex 与 OpenCode 的本机 CLI。

## 核心体验

- 添加目录后即可开始对话，按会话保存引擎、模型和原生上下文。
- 流式阅读回复与工具输出，在需要时审批、取消或重试。
- 多工作区、多会话并行，切换时保留各自的运行状态。
- 搜索和整理历史，导入 Claude / Codex 终端会话并继续使用。
- 就近查看文件、Diff 和 Git 状态，完成暂存、提交与推送。
- 通过后台下载和安装重启更新应用。

## 界面结构

左侧导航切换工作区、文件与变更；主区使用聊天、文件和 Diff 标签；右侧按需显示工具详情。设置集中管理外观、CLI、模型服务、会话、Git 和更新偏好。

低频配置放在设置中，当前任务的运行状态、审批和恢复入口保留在对话附近。长内容可独立滚动，窄窗下保持输入与主要操作可用。

## 边界

- 当前支持 Windows x64，暂不承诺其他平台。
- 模型、凭证与工具执行由 CLI 提供，Conduit 不另建登录体系或模型计费服务。
- 文件预览和 Diff 目前只读，不替代代码编辑器。
- 并发会话共享工作区文件；需要隔离时使用不同 Git worktree。
- 自动更新默认下载后提示，重启由用户操作或明确启用的空闲安装策略触发。
