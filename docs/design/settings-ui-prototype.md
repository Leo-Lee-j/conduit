# Conduit 设置 UI 交互原型

## 打开

直接用 Chrome / Edge 打开 [settings-ui.html](settings-ui.html)。无需编译 Rust、启动应用或本地服务器；HTML 与 `settings-ui/` 文件夹应保持相对位置。

本原型只展示设置主区，不模拟或自动隐藏原工作台左右面板。顶部“主区宽度”是扣除外部面板后的可用宽度，实际值受浏览器窗口限制。

## 本轮范围

- **外观与字体**：浅色/深色/跟随系统、本机字体、界面字号12–20、独立聊天与代码排版、实时内容预览。恢复界面默认只恢复界面字体/字号。
- **会话设置**：新会话默认服务/模型、默认权限、显示偏好、自动命名四段，各自说明生效范围。
- **模型与服务**：按引擎及来源浏览、独立默认摘要、模型详情、独立编辑表单、引用保护及模拟连接验证。
- 原型导航中的其余入口仅展示目标信息架构，未实现的页面明确不可点击。

所有服务、模型目录、端点、会话与验证均为演示数据。所有更改仅保留在浏览器内存，刷新即重置。不请求模型服务、读写Conduit配置、读取真实凭据、启动CLI或将输入写入localStorage。API Key输入只用于演示遮罩，保存时仅记录是否已配置，不保存输入文本。

## 评审方式

1. 在“正常 · 1200px”依次查看三页；外观页对照右侧内容预览。
2. 切到“窄主区 · 640px”或“480px”，用文字分类选择器导航；服务列表与详情按页内流程切换。
3. 在“中等 · 960px”切到20px字号，验证长标签、错误及按钮能重排；编辑表单打开时缩小窗口，输入不得丢失。
4. 切换浅色/深色，再用键盘Tab、Enter、Esc完成导航、搜索与表单操作。
5. 勾选只读实例：导航、引擎浏览、搜索仍可用，设置写入不可用。
6. 选择模拟连接失败，运行明确标记为模拟的验证；切引擎后旧结果不得覆盖当前上下文。

## 必须区分的语义

- 查看服务只改变浏览对象；只有“设为新会话默认”改变对应引擎的新会话默认。
- 新会话默认不改已有会话引用；编辑共享服务可能影响引用它的旧会话未来使用，保存前说明影响。
- 连接测试通过不等于实时在线，更不等于原生CLI已将它加载到会话。
- 默认权限用于待建/新会话；显示偏好即时生效；自动命名按策略作用于后续轮次，不批量改历史。
- 切换引擎是查看上下文，不是修改默认引擎或认证。

## 响应式与视觉

采用Conduit浅/深色中性色、系统字体与统一线形图标。普通设置用对齐表单，不逐项卡片化；服务浏览与编辑分离。内容预览承载细节，导航保持克制。

使用实际逻辑宽度预算，不写死“960px三栏”：先退化服务列表/详情，再将设置分类退化为文字选择器；独立编辑表单和输入节点不因主区重排而重建。字号参与宽度预算，浏览器处理DPI，代码不重复缩放。

## 本轮不实现

原生GPUI代码接入、配置字段迁移、实际模型目录获取/服务认证、服务版本化、字段级搜索定位、复杂返回历史、新抽屉系统、应用发布。

导航组合是目标设计的原型；实际接入须先建立稳定路由与旧入口映射，并保留现有未提交的服务页增量。

## 自动化验证

`settings-ui/check.cjs` 使用 Playwright 与本机 Chrome/Edge，直接读取file URL。工具包安装在系统临时目录，不修改仓库依赖。验证报告及参考图位于 `settings-ui/test-report.json`、`settings-ui/previews/`；报告状态以实际运行结果为准。

```powershell
npm.cmd install --prefix "$env:TEMP\conduit-settings-prototype-tools" --no-save --package-lock=false --ignore-scripts playwright
node docs/design/settings-ui/check.cjs
```

环境可通过 `PLAYWRIGHT_MODULE` 指定Playwright模块路径，`PROTOTYPE_BROWSER` 指定浏览器可执行文件。

此HTML原型可验证展示与交互，但不能替代原生应用中的配置、进程、异步探测和回归测试。进入GPUI实现前仍需确认最小支持主区宽度以及默认来源失效时的实际启动策略。

## 设计与协作

产品、美术/交互、技术、QA四个独立agent进行了两轮评审；随后分工实现三个页面、公共壳与浏览器验收。设计方法参考 **Unslop by Damir Sokolovsky (@heydamir)**，其技能指南采用CC BY 4.0许可；本原型保留现有产品主题体系，不引入生成图片。
