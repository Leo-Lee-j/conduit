# 模型与服务 · 调整稿

独立、可离线打开的 HTML 设计预览。以用户提供的 B 紧凑表格为主体，保留 A 的默认配置摘要，使用详情抽屉呈现模型和使用会话。

## 方向

- 场景：Conduit 的 CLI 服务配置与新会话默认选择。
- 风格：延续原稿灰白表面、蓝色强调和细边框；采用系统字体。
- 层级：当前默认 → 服务比较 → 按需查看详情。
- 重点：默认摘要的蓝色左边线，服务表格保持安静。
- 识别细节：原生 CLI 配置与 cc-switch 管理来源明确区分。

## 调整依据

- A：服务信息稀疏，卡片和重复按钮造成过长页面。
- B：引用展开打断行高；默认选择容易与浏览选择混淆。
- C：当前详情内容不足以支撑常驻双栏。
- 共通：CCS 缩写、引用术语和底部解释增加理解负担。

## 预览范围

支持默认切换、查看模型、查看会话、关闭抽屉、设置导航过滤和添加本地示例服务。数据仅保留在内存，刷新即恢复。

服务名称、地址和数量取自设计稿。原稿未提供的模型名称和其余会话标题均标为布局示例。引擎切换、其他设置导航及外部编辑仅提示预览范围，不连接真实服务，不读取或写入应用配置。

`overview.png` 为 1200 × 960 总览，`details.png` 为会话详情展开状态，`compact.png` 为 1000 × 800 紧凑窗口。

设计流程参考 unslop by Damir Sokolovsky (@heydamir)，CC BY 4.0；本目录为 Conduit 的设计预览，不包含原技能代码。

## 验证

已在 Chromium 中检查：模型/会话抽屉、默认服务切换及恢复原生配置、添加示例服务、导航过滤、1000px 与 390px 宽度无页面横向溢出、无 JavaScript 页面错误。总览和详情在 1200 × 960 下截图复核；窄窗口使用内部滚动，抽屉操作栏固定。
