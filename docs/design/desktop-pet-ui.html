字符小猫，住在桌面上

Conduit / 桌面宠物 · 原生透明窗口修订

待机只显示字符形象。直接点一下，小猫先想一想，再用气泡回应。模型和语气留在设置里，桌面留给小猫。

一个小问题，一点点解决。

01 / 只留形象

系统窗口也不绘制标题栏、边框或阴影，等宽字符用细描边适配桌面底色。

02 / 点击就回应

表情与省略号换帧表示思考。处理中重复点击不再发起请求。

03 / 反馈后回到陪伴

气泡向左上方出现，角色大小保持不变。气泡可收起，拖动不会误触聊天。

实际应用：设置 → 插件 → 桌面宠物。右键显示操作菜单；Esc 收起气泡；回复约 25 秒后自动收起，悬停阅读时暂停。
