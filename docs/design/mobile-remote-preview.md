# Web 远控试用

桌面构建启用 `remote` 功能后，可以在手机浏览器查看会话、发送文本、停止本轮，以及新建、改名、置顶、归档和取消归档。停止后可以在原会话发送下一条消息。运行中的审批和提问在电脑上处理。

## 在电脑上预览

```powershell
cargo run --locked --features remote --bin conduit
```

1. 选择要共享的工作区，打开「设置 → 通用 → Web 远控」。
2. 点击「开启 Web 远控」，将 HTTPS 地址留空。
3. 把剪贴板中的配对链接粘贴到这台电脑的浏览器，输入设备名称并配对。

## 用手机连接

两台设备加入同一个可互通的 tailnet。电脑的 Tailscale Serve 使用 HTTPS，把流量转发到 `127.0.0.1:47831`。Conduit 绑定这个 loopback 地址。手机使用带用户身份的 tailnet 设备访问。

```powershell
tailscale serve --bg http://127.0.0.1:47831
```

在 Conduit 的远控对话框中填入 Serve 输出的 HTTPS 地址，开启远控，然后通过私下渠道在手机的 Safari 或 Chrome 中打开配对链接。配对链接一次有效，五分钟过期。一个浏览器可同时配对，完成新配对会撤销旧浏览器。可在电脑关闭远控以撤销访问。每次重启 Conduit 后需重新开启和配对。

## 当前范围

- 授权范围固定为开启时选中的一个工作区。已有会话沿用桌面设置，新建会话采用桌面配置的默认选项。
- 发送等到保存成功后才放行 CLI。遇到已有任务或桌面待发消息时，草稿留在当前浏览器标签页。断线时用原请求查询结果。
- 手机归档保留桌面标签和草稿。网页历史按页返回用户和助手文本，长消息在电脑上查看完整内容。
- 网页通过 SSE 收到刷新信号，重连后重新读取当前状态。手机真机及蜂窝网络路径待验收。应用配置、移动审批、二维码配对与持久设备授权仍在后续设计中。

完整目标见 [手机远程控制设计](mobile-remote-control.md)。其中 OpenAPI 是完整方案草案，试用版接口随实现演进。
