# C 搜索与任务

- 页面以顶层域、域内分类、页内任务分三层，11 类设置均可发现。
- 外观页默认「聊天文字」，五个任务保持当前值摘要；改动后任务末尾出现一个小点。调整仅存本页内存。
- 完整交互：`#search` 搜索及 Enter/上下键，Ctrl F，Esc；`[data-domain]`、`[data-page]`、`[data-task]` 导航；`#chatSize` / `#uiSize` / `#codeSize` 范围控件；`[data-line]` 行距；`#reset` 独立重置；`[data-mode]` 主题；`#lineNumbers` / `#highlight` 开关。
- 窄于 570px 时任务改为文字下拉 `#task-select`，内容改为自然页面滚动。不是仅保留图标的不可识别导航。
- 聊天预览使用合成内容，未读取用户会话。模型与服务、会话设置提供范围正确的结构示例；其它类别明确说明未展开详细表单。
- 当前方向的代价：跨域会多一次选择，纵向任务切换也比长表多一次点击，但更容易预测设置位置。
- 首轮修正：压缩不必要的标题与组间垂直距离，让聊天预览在 900px 高度可完整看到；手机域标签不再换行；背景选项真正更新预览。
