# A 清晰双栏

文件：`dir-1.html`。原生 HTML/CSS/JS 单文件，logo 来自 `assets/app-icons/source.png` 并以 base64 内嵌。全部修改仅存在于页面内存，无应用配置读取、网络请求、localStorage 或真实保存。

## 设计理由

- 固定 216px 文字导航，将十一类放进「工作台 / AI与工作流 / 扩展能力 / 应用维护」四域，Git 工作流归入 AI与工作流；800px 时收至 190px，移动端使用可展开的完整文字目录。
- 设置作为独立空间，标题明确；主题 / 文字 / 背景使用短标签，文字再按界面 / 聊天 / 代码区分，不把全量配置堆在同一长页。
- 主区域使用行式表单，只有结果预览有轻边界。青绿只标记选中、操作和焦点，浅灰用于分层。无装饰性主视觉、渐变或卡片堆叠。
- 默认聊天设置包含字体、字号、行距，下方紧凑对话与代码同时验证独立字体。界面字体也会实时影响整个设置空间。
- 主题与背景沿用同一预览位置。初始为浅色以呈现 A 的轻中性色方向；系统模式监听浏览器系统配色，浅色和深色主题各保存独立选择。
- 搜索索引覆盖具体字段和全部分类，跳转会展开对应标签、移动焦点并短暂标记目标。
- 会话设置通过「新会话 / 已有会话」明确生效范围；服务编辑处注明共享服务 ID 的影响，避免把修改默认模型误解为改写已有会话。
- 设置修改自动更新内存与预览，不设二次保存确认。底部为完整一句状态说明及「重置当前组」，手机端压至 53px 单行。
- 重置仅影响当前标签及字体分组：文字只重置界面、聊天、代码中的当前一组；主题重置模式及浅深主题；背景只重置背景。
- 预览元信息简化为「示例对话」，说明仅显示当前字体与字号；去掉装饰性中点，保留代码区的功能性等宽字体。

## 交互选择器

| 功能 | 选择器 / 操作 |
| --- | --- |
| 十一分类 | `.nav-item[data-page]`，默认 `appearance`，完整示例 `sessions` / `models` |
| 外观短标签 | `[data-tab="theme"]` / `text` / `background` |
| 字体分组 | `[data-scope="ui"]` / `chat` / `code` |
| 字体 | `#font-family`；选项按分组切换，未安装字体使用本机回退 |
| 字号 | `#font-size-range`、`#font-size`、`#size-minus`、`#size-plus` |
| 聊天行距 | `[data-line="1.4"]` / `1.6` / `1.8` |
| 代码开关 | `#line-numbers`、`#syntax`；使用 `role="switch"` |
| 主题 | `[data-theme-mode="system"]` / `light` / `dark`、`#light-theme`、`#dark-theme` |
| 背景 | `[data-bg="default"]` / `gray` / `green` |
| 即时预览 | `.conversation`、`#code-preview`、`#preview-caption` |
| 搜索 | `#search`；Ctrl/Cmd+K 聚焦，输入“代码字号”等，方向键选择、Enter 跳转、Escape 关闭 |
| 范围示例 | `[data-session="new"]` / `existing`；内部 `[data-jump]` 导航至字段 |
| 服务页 | `[data-model-tab="services"]` / `defaults` |
| 服务增改 | `#add-service`、`#service-list button`、`#service-dialog`、`#service-name`、`#service-form` |
| 默认服务 | `input[name="default-service"]`；添加示例后可切换 |
| 重置当前组 | `#reset-page`；文字按 scope，主题与背景按 tab；模型页按服务列表或新会话默认分别重置 |
| 自动更新状态 | `#change-status`；每次修改自动更新，无保存按钮和绑定事件 |
| 移动导航 | `#menu-button`、`#sidebar.is-open`、`#mobile-scrim`；Escape 收起 |
| 返回工作台 | `#close-settings`、`#workbench`、`#reopen-settings` |

所有标签组支持左右方向键及 Home / End，控件提供可见焦点。字体范围下限为 14px，界面字号上限 18px，聊天与代码上限 22px。手机端设置内容纵向滚动，底部单行状态与重置按钮保持可见。

## 局限与交接

- 三方向的截图、视觉打磨与多尺寸浏览器验证由主代理统一执行；此文件只做 A 的初稿，不读取或依赖其他方向。
- 其余八分类为明确标记的结构占位；工作台返回为结构预览，不实现项目树或会话业务。
- 服务新增与编辑只演示本地 CLI 名称和默认服务关系，不检测连接，不包含密钥、不编造模型型号；刷新恢复初始示例。
- 重置服务列表时，若当前默认服务已被移除，仅将失效引用恢复至初始本地 CLI；重置新会话默认不会修改服务列表。
- 「柔和浅色 / 柔和深色」及背景色明确属于设计示例，不承诺与现有主题清单一致。
- 字体使用系统回退，不枚举真实安装字体。系统默认与 Segoe UI 在部分 Windows 环境可能视觉相同。
- 同屏代码用于验证聊天和代码的独立排印；显示的设置对象是说明性代码，不对应应用持久化格式。
