# 品牌与资产

唯一出现在三版界面中的产品品牌为 Conduit。真实 logo 来源：仓库 `assets/app-icons/source.png`（用户提供的原图，见该目录 README）。深色背景、白色 C、青绿色通道是已经存在的资产。

三版将图标按原比例内嵌，不重画标志。强调色从青绿色通道推导，浅底操作色加深以满足对比度，深底选中色适度提亮。中性色各版随操作密度调整。辅助状态与品牌色分工明确，错误不可仅靠颜色识别。

中文使用 Microsoft YaHei UI，西文使用 Segoe UI，代码使用 Cascadia Code/Consolas。字体为系统回退，不远程下载。

参考产品仅在研究文件中记录，不在 Conduit 原型里摆放其它品牌 logo。无摄影素材需求，主要图像是按真实设置内容绘制的可交互界面预览。
