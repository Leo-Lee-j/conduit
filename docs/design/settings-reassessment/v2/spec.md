# Conduit 设置菜单第二轮

日期：2026-11-26。用户原话：「我倾向于更加技术风格，紧凑布局，信息密度高」。此前要求层级与布局、视觉质感、操作效率共同改善；此轮保留三个不同结构的方向，尚未选择生产实现。

## 共同内容与验证口径

- 以 1440×900 桌面为共同比较画布；检查 1100×800、800×800、375×812。首屏可直接操作主题、界面字体、聊天字体、代码字体等多个组，不能仍靠三层 tab 一次展示三项。
- 十一分类和四域沿用上一轮 spec.md。统一主样本为外观与字体，至少包含主题模式、浅色主题、深色主题、界面字体和字号、聊天字体/字号/行高、代码字体/字号/行号/语法高亮、背景。以真实设置数量衡量密度，不靠微缩文字。
- 样例默认值：跟随系统；界面 Segoe UI / 14px；聊天 Segoe UI / 15px / 1.6；代码 Cascadia Code / 13px，行号及语法高亮开启；背景默认。所有值是设计示例，不代表读取当前用户配置。
- 表单正文 14px，辅助说明 12px；桌面控件高 28–32px、行高约 36–44px、分组间距 12–20px，满足本次明确的紧凑偏好。窄屏扩大点击区。数字、代码、快捷键可用等宽字体；中文名称保持系统 UI 字体。
- 真实 logo 使用 assets/app-icons/source.png 内嵌；无需装饰插画、假终端、虚构配置键、连接指标、营销信息。纯本地单文件 HTML，无外部字体/CDN/网络。
- 即时修改只存浏览器内存；不写应用配置。状态使用「预览已更新」，底部标「设计预览 · 不写入应用」。沿用产品自动应用的概念，不加保存按钮。
- 字体与字号独立作用于界面/聊天/代码；预览真实反映调整。分组重置只影响该组。搜索能过滤/定位具体项，空结果可恢复；主题切换、键盘焦点、重置、至少一个开关可操作。
- 模型/会话等次级分类可为诚实的结构示例；不能编造尚未实现的工作区覆盖、同步、服务在线状态。浏览引擎不改变默认；新会话默认不改旧会话；共享服务编辑可能影响已有引用。
- 保留第一轮文件，全部新内容写入 v2/，不改 src/、不提交。

## 形式来自内容

设置是开发者反复扫描和微调的参数。空间分配应突出名称、当前值与作用对象，减少页面切换；技术风格来自可比较的对齐和直接反馈。聊天与代码预览是实际内容，不是装饰素材。

## 三版共性与差异

三版均满足紧凑且高密度。A 以目录和分组属性行组织；B 以宽预览和紧凑检查器组织；C 以可筛选参数表组织。禁止只换配色或把所有输入框缩小。
