# 第二轮逐屏意图

用户目标为桌面技术风格、紧凑与高密度；主视觉就是可操作参数与实时阅读效果。没有宣传插图需求。

- A 桌面：左目录、密集分组、右侧三种阅读预览。宽度减少先收辅助预览，再将类别变为可选入口。
- B 桌面：领域导轨与文字分类、中间聊天代码工作样本、右检查器。窄宽时让检查器先呈现，预览顺延。
- C 桌面：横向领域/分类、筛选工具条、五组参数表、底部短预览。名称/当前值/作用范围三列可横向扫读；1440×900 目标让 13 项与短预览同屏。
- C 手机第一屏：四域导航仍有文字；表格只保留名称/当前值。保留主题、界面和聊天分组，不压缩字体到难以阅读。
- C 手机第二屏：代码和背景参数后直接展示聊天/代码效果，交互反馈与编辑相邻。

polish.py 对手机长设置表的「只有文字和框」提示已人工复核。此处是设置编辑器，不是营销长页；分组参数表与真实对话/代码分别承担编辑与结果，增加无关图片会损害用户要求的密度，因此不添加装饰素材。表格和预览均是真实可操作 HTML。
