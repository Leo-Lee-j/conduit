# A · IDE 控制中心（优先推荐候选）

来源机制：JetBrains 官方设置截图所示“搜索和分类树在同一导航层，内容保留分类路径”。真实截图 refs/jetbrains-settings.png，页面资料 refs/jetbrains.txt。只借导航的空间稳定性，不借 Apply/OK 保存语义。整体是 Conduit 技术桌面工具，石墨深底、细中性色边线、小面积青绿选中。

骨架：独立全窗设置；顶部紧凑品牌/返回/全局搜索，左216px分组导航，右统一面包屑+页标题+作用范围；普通偏好紧凑属性行，必要说明就在行下；资源页主区自带约30%列表/70%详情，详情中的编辑是局部状态；无常驻外观预览第三列。左侧11项全部可见，四分组：工作台(通用/外观/快捷键)、AI与工作流(引擎/服务/会话/Git)、扩展(三项)、维护。

重点签名：服务详情顶部清楚列出“来源、用途、关联会话”，默认服务是独立动作；所有实体都用同样的列表/详情法。密度依靠对齐和内边距，不能凭小字体。首屏默认services，展示左导航、服务列表、选中团队网关详情、模型行和关联会话，不要留很大空白。

结构分层强、迁移风险较低。标题20px左右而非营销页大字。暗色但不纯黑，不使用发光/渐变/巨大品牌标识。1440×900；手机折叠导航，资源列表进入详情可返回。完整要求见spec.md。单文件输出design-demos/dir-1.html，说明notes-a.md。
