# Conduit 完整设置体系 · 第三轮共同设计输入

日期：2026-11-26。目标：供用户选方向的高保真交互方案，不改动原生业务代码。

用户原话：「我不是很满意这个效果，而且没有所有菜单统一设计。调研下市面上成熟产品的设计方案。灵活运用 huashu skill。我允许你重构整个设置菜单。给我方案」。偏好：技术风格、紧凑布局、信息密度高；三个方向都要。

## 共同问题与范围

现有设置嵌在聊天工作区中：主侧栏约 384px，再加 184px 设置导航，外观还常驻 280px 预览。全局搜索与局部搜索上下叠放。仅外观采用了新属性行，其他管理页继续用各自页面结构。本轮必须统一整个设置系统，不能拿外观页作为全部交付。

采用独立设置视图（同一应用窗口内），暂时收起工作区侧栏和右侧详情，返回工作台恢复原布局及焦点。原型返回只显示模拟工作台/返回设置，不跳到真实程序。不要把 11 个页面都塞成开关表；用四类共同模板：偏好、资源列表/详情、快捷键、配置编辑。

11 个可见入口均必须有实质内容及可点击导航。页面键固定为 general, appearance, shortcuts, engines, services, sessions, git, skills, mcp, plugins, maintenance。可以重组导航但不能遗漏。

## 演示数据和行为边界

所有示例列表明确为演示，不扫描本机，不连接真实服务、不安装。服务样本：团队网关（本地，https://gateway.example.test/v1，模型 team-code、team-fast，关联会话3）；个人开发（本地，https://dev.example.test/v1，dev-code，关联0）；CCS 工作配置（cc-switch，来源只读）；CLI 原生配置。初始新会话默认=团队网关/team-code。浏览个人开发不改变默认。

Skills示例：code-review（工作区）、release-notes（全局）、team-style（插件托管）；MCP示例：workspace-files（stdio，已连接/演示，工具3）、docs-search（HTTP，未验证）、issue-tracker（HTTP，检测失败）；插件示例：内置文件图标、Workspace Icons（本地演示）、Mono Icons（本地演示）。凭据使用环境变量名 CONDUIT_API_KEY，不放真实密钥。路径用 D:/workspace/conduit 等示例。

偏好改动自动应用/保存；服务、原生配置有自己的保存取消。不能放一个普遍“保存全部”。未保存服务编辑要保护离开；选择新会话默认不能修改已有会话；共享服务编辑说明会影响引用它的会话后续请求。只读仍能搜索、切换页/查看引擎，写操作禁用；真实原生版本应有保存中/失败/重试。

## 原型约定

- 三个单文件HTML：design-demos/dir-1.html / dir-2.html / dir-3.html。HTML/CSS/JS内嵌，无CDN、无外网字体、无框架。各方向独立实现，不读取其他方向HTML。
- 同样尺寸：1440×900主屏，1100×800、800×800、375×812用于适配验收。桌面行高36–44可按用户紧凑要求采用，正文14+、辅助12+；窄屏点击区44+、正文16。无需制造大标题、大卡片或铺满装饰。
- 默认均打开 services。所有页面通过 [data-page="键"] 导航按钮进入，并更新 body.dataset.page。支持 #services 等hash深链。
- 搜索 #settings-search 必须跨11页搜索中文标签/技术字段，展示结果后能进入对应页。Ctrl+K聚焦，Esc清除搜索/关闭局部层优先于退出。
- 至少交互：全部导航、偏好开关/输入；服务选中与详情、编辑保存取消、未保存离开保护、显式默认；Skills/MCP已安装发现tab；MCP模拟检测；外观独立字体与预览；快捷键编辑冲突；只读切换（用原型工具入口明确是演示）。
- 测试入口推荐公开 window.designNavigate(page)，但用户导航必须可点击；关键元素加data-action说明。JS保留当前页面状态；输入别每键重建导致丢焦点。
- 页脚小字“交互原型 · 示例数据，未连接本机”。没有后端的按钮提供具体模拟反馈/详情，不能空点击。不要把实现技术写进产品流程。
- 每页实质内容可滚动；搜索/导航/状态固定位置。各方向设计模式贯穿所有页。
- 暂存说明仅写自己的 notes-[a|b|c].md，列出结构/全页覆盖/交互/限制。不要改其他文件或原生源码。

## 共同验收

11/11菜单；4类模板统一；有效空间；单一搜索入口；区分查看上下文和写入作用范围；浏览≠默认；检测≠加载；自动保存与表单保存分明；窄屏无页面横溢；可键盘操作；主题和字体不丢焦点。演示状态与生产状态明确分开。
