## A 表单一致性补修 · 第一轮（2026-11-26）

用户反馈：“有些地方的输入框和下拉框的样式没有统一”。本轮在已批准方案 A 内迭代，沿用 huashu-design 的看图复核方式，不重开设计方向。

原先 70 张截图保存在 `target/settings-controls-before/`。新增会话命名/Git 生成展开、CLI 高级配置、服务新建/编辑、MCP 新建和 Skill 编辑，覆盖五种视口/字号组合，共 105 张。第一轮保存在 `target/settings-controls-round-1/`。

1. 原生 small 控件（24px）、自定义 32px 控件、无边框圆角菜单触发器并存。引入共享控件样式：28px 高、14px 字、8px 水平边距、4px 圆角；下拉统一右侧箭头。保留原生焦点/禁用/展开颜色及保存事件。
2. 数字步进器额外 padding 使外框比统一后的输入框高，数值也较小。删除重复 padding，外框统一 28px，并使用主题输入背景/边框、14px 数值。宽度保持紧凑，随明确的字号设置缩放。
3. 服务编辑中 API Key 字段独立限宽，和地址字段错位。移除这个局部限宽，让同一表单使用一致的字段边界。多行内容独立保留编辑高度，但字号、边框圆角接入共享规范。

第一轮弹窗截图处于入场渐显中，尚不能据此判断最终背景不透明度。截图等待时间从 150ms 调整为 450ms，第二轮复核静止状态；未为此改动原生弹窗组件。
