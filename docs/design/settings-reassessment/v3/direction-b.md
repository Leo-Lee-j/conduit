# B · 资源浏览器

来源机制：Raycast 已安装扩展作为可选择对象，并把对象配置/命令放在其详情。参考已下载的 refs/raycast-agents.png 和 refs/raycast-settings.png，以及 refs/raycast-settings.txt 关于Browsing Extensions/Extension-Specific Settings。只借对象归属的清晰性，不复制Mac磨砂/大图标/巨大的中心标题。

骨架与A必须不同：顶部四组横向导航（工作台、AI与工作流、扩展能力、应用维护），第二行当前组的页面tab。主区直接用资源浏览器：左270px当前页的对象列表或设置章节列表，右对象/章节编辑文档，11个总菜单不再常驻左栏。顶栏单一全局搜索。普通偏好页也有章节目录，点击显示对应章节而非把全部字段堆成长页。每组tab保留当前项。所有页data-page入口在当前组显示，并可通过全局搜索访问。

视觉：浅灰工业软件底，深墨文字、冷灰分割，少量钴蓝操作；主区边界清楚、密度高；路径/ID用Consolas，中文系统字体。不要做卡片网格或海报；列表统一44–48px/两行，详情为紧凑文档。服务页默认团队网关，显示环境变量凭据、两模型、关联会话、显式编辑/默认操作。

签名：引擎/范围上下文在资源列表顶部，详情标题显示对象来源和影响范围。对多服务、多扩展用户更顺手，分类总览需要多一层点击。窄屏同一资源列表->详情，并保留返回。所有11页实质内容及交互参考spec.md。输出design-demos/dir-2.html，notes-b.md。
