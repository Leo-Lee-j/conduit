# C · 设置索引

来源机制：VS Code官方Settings editor的搜索过滤/modified机制，refs/vscode-settings.png、refs/vscode-filter.png和refs/vscode.txt。只借“搜索能成为整个设置的入口”，不借其长段落表单布局。这个方向将常用配置项与资源索引置于统一、可过滤的技术目录。

骨架与A/B不同：全宽顶部搜索、横向11个短菜单（按4组视觉分隔，可换行/窄屏下拉），主区没有常驻垂直侧栏；下方是全宽紧凑索引表。偏好表列为名称/值/生效范围，分组小标题嵌在表内；资源表列名称/来源/状态/用途，点一行打开右侧可关闭检查器或窄屏全宽详情。检查器只为当前选中项出现，不用永久第三栏。默认services表+团队网关检查器，能关闭看全表。快捷键天然表格，Git长提示词在展开行或检查器里。辅助说明随选中行出现，不散落各处。

视觉：暖中性极浅灰工作纸面+墨黑文字+克制橄榄绿/赭色焦点，仍是技术软件，不用纸纹/衬线/印章/终端命令行。少量密集行分割；工具条精简；路径与ID等宽；所有正文>=14。

签名：一个索引查询设置、对象与来源；明确搜索域，已修改只用于偏好，不把连接失败混成“已修改”。作用范围为只读信息，不添加不存在的全应用/项目任意覆写能力。最大密度，发现性较弱，因此作为重度键盘用户方向。Ctrl+K搜索，中文结果可跳转。所有11页实质内容及交互见spec.md。输出design-demos/dir-3.html，notes-c.md。
