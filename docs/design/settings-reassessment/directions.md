# 六张方向卡

共同输入见 spec.md。六候选只写方向卡，A/B/C 三版做成完整可操作 HTML。

## A 清晰双栏（入选）

- 逻辑与来源：最佳设计师推演，Dieter Rams 的功能分层与一致控件原则；仅借思想，不声称本人设计或认可。
- 借的机制：功能层级决定空间层级。固定 216px 文字分类；页标题 26px、正文 14px、说明 12–14px；主要内容最大宽 1040px。
- 自己长的表达：青绿来自 Conduit logo，灰白底和 Windows 字体来自原生桌面语境，不复制硬件旋钮和工业产品外形。
- 主角素材：真实外观设置及一块聊天/代码效果预览。
- 骨架：独立设置空间、左侧四组分类、页标题和搜索、主题/文字/背景短页；默认打开文字，界面/聊天/代码分开。
- 胆量花在哪：关闭设置时回到原工作台，设置时收起项目树，给设置足够空间；这是待选择的结构提案。
- form 来自内容：设置本身是层级明确的偏好项，行式表单和短页让一项修改有一个稳定位置。

## B 预览工作台（入选）

- 逻辑与来源：最佳设计师推演，Bret Victor 的直接观察结果思想；仅借反馈机制，不模仿具体作品。
- 借的机制：控件与效果同时可见。保留 176px 项目上下文、约 184px 设置导航；内容区按约 43/57 分配编辑和预览，窄宽先收起项目上下文再下置预览。
- 自己长的表达：深石墨与柔青绿来自 Conduit 原生工作台和 logo；使用 Segoe UI/Microsoft YaHei UI，不做终端皮肤、发光边框或全等宽正文。
- 主角素材：包含用户问题、助手答案、代码段的真实可读预览，字号/行距立刻反映在里面。
- 骨架：保留会话上下文的设置工作台；分类/编辑/效果三层；页内界面/聊天/代码标签；主题/背景仍可发现。
- 胆量花在哪：把最多的有效面积给实际阅读效果，而非表单边框。
- form 来自内容：Conduit 的长期阅读与代码任务要求调整时直接观察聊天和代码两种结果。

## C 搜索与任务（入选）

- 逻辑与来源：现实参照 VS Code 官方 Settings editor，来源 https://code.visualstudio.com/docs/configure/settings；研究原图放忽略目录 target/settings-reassessment-refs/，不公开提交第三方图像。
- 借的机制：搜索同时显示类别路径和精确设置落点。官方原图 1286×466，导航约占设置主体四分之一；ref_card 测得深近黑 #1F1F1F 占 80%，本方案不借这层深色表达。这里改为四域顶部导航，把内容层级从纵向长表改为任务清单加详情。
- 自己长的表达：亮石灰中性色、深色正文、品牌青绿选中；横向域导航与简短任务清单是本次结构，不复制 VS Code 活动栏、蓝色主题或 JSON 编辑器。
- 主角素材：左侧各任务当前值摘要，右侧聊天文字设置及真实对话预览。
- 骨架：顶部四域、域内分类行、左任务索引、右设置详情；搜索结果选中后跳具体字段；已修改只统计当前演示值。
- 胆量花在哪：用横向域切换腾出纵向宽度，让不知道分类名的用户也可搜到字段。
- form 来自内容：十一类设置需要发现和定位，域/分类/字段路径是可见的导航骨架。

## D 沿用旧原型的单页阅读（备选）

- 逻辑与来源：现实参照，本仓库 docs/design/settings-ui.html 及 previews/appearance-normal-1200.png，已亲眼查看。
- 借的机制：设置与排版预览并排，参考图中侧栏约占 19%，右预览约占总宽 27%；ref_card 的参考板缩放图 1256×900，浅中性白占 89%，下方内容密度最高的一段占 18%，体现长表末端偏密。
- 自己长的表达：保留品牌资产与系统字体，把长说明压到需要时展开，使用短组标题；不复制原型的长篇说明和层层横线。
- 主角素材：外观单页中的预览；骨架为两栏长页；胆量只用在减少页面跳转；form 来自需要连续比较的文字设置。
- 未选原因：与 B 功能相近，但长页首屏仍容易看不到聊天/代码设置。

## E 色块任务台（备选）

- 逻辑与来源：秒数轮盘 S=42；网页 20 种中抽到 3「孟菲斯复古拼贴」，已查看 web/03-memphis-maximalism.jpg。
- 借的机制：不同任务块用尺寸与空间分区，不借唱片、复古字、拼贴纹理或撞色。
- 自己长的表达：只保留中性底与 Conduit 青绿，统一系统字体与对齐；主角是主题、文字、背景三个任务模块。
- 骨架：任务大块入口展开内联控制；胆量花在模块尺寸反差；form 来自设置频率差异。
- 未选原因：密集开发工具里大块入口会增加一次进入操作，视觉形式收益小于效率损失；相较样张主动放弃装饰，不能声称完整风格还原。

## F 主题色谱（备选）

- 逻辑与来源：同次秒数轮盘 S=42；东亚 12 种抽到 7「中国传统色·节气色谱」，已查看 east/07-traditional-colors-solar-terms.jpg。
- 借的机制：连续色谱选择与明确的当前指示；不借节气、纸色、书法或衬线排印。
- 自己长的表达：从真实已安装主题取色，基于 Conduit 聊天内容展示主题；主角为并排小预览。
- 骨架：主题图录加下方字体控制；胆量花在主题可视化；form 来自真实主题选择。
- 未选原因：对外观页有用，难以成为模型服务、会话和扩展页共享的导航骨架。

三版是完整方案差异，不是布局、质感、效率各分一版。三个目标在每版都必须覆盖。
