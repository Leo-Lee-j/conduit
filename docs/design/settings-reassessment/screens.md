# 逐屏内容与主角

本次是设置界面，不是宣传落地页。脚本按图片面积判断，不能识别由 HTML 绘制的真实可操作设置与聊天预览，因此「只有文字和框」警告需按界面用途人工复核，不能用装饰大字或无关图片消除。

| 方向 | 桌面首屏 | 窄窗第一屏 | 窄窗后续屏 |
| --- | --- | --- | --- |
| A | 分类、聊天文字控件及同屏小预览 | 文字分类选择与表单 | 聊天预览、其它任务入口 |
| B | 工作台上下文、配置栏、大面积聊天代码预览 | 收起项目上下文，保留设置导航/文字分类 | 配置结果与聊天代码预览 |
| C | 顶部域与分类、左任务摘要、右聊天文字与预览 | 搜索、文字任务下拉、字体字号行距 | 随控件改变的真实聊天示例 |

相邻屏的职责分别为操作和效果。主角是可以玩的阅读调整，不额外引入海报装饰。375px 仅验证收缩能力，主要目标仍是 Windows 桌面设置面板。
