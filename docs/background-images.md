# 应用背景图

## 目标与范围

通过 Wallhaven 官方匿名 API，在“设置 → 外观”中搜索、浏览并应用应用背景图，不要求账户或 API Key。默认关闭，已有安装保持原外观。第一版支持关键词、分类、热门/最新/随机排序、分页、手动换图、背景强度及离线恢复。自动轮换、动态壁纸、实时模糊不在第一版范围。

设计先于实现落地；本文维护行为与性能边界，逐次验收产物写入 `target/`。

## 数据来源与交互

- 官方契约：[API v1](https://wallhaven.cc/help/api)。搜索使用 `/api/v1/search`，固定 `purity=100`，不发送凭据。分类使用 general/anime/people 位掩码；热门使用 `sorting=toplist&topRange=1M`。
- “启用背景图”使用独立 switch；“浏览 Wallhaven”在背景强度下方展开搜索区，可收起，不再打开弹窗。开启但未选图时给出选择提示。移除原页面跳转按钮。
- 搜索支持官方 29 色色板，使用 `colors` 参数；“只看纯色背景”组合必选的 `+"solid color"` 标签与关键词。该标签可能包含带图案的单色背景，不等同于像素严格一致的纯色；不额外下载原图分析。精确 `id:` 查询不能组合此标签，显示错误。换页保留颜色、标签、关键词和随机 seed。
- 搜索框和搜索按钮为 36 px 高，支持 Enter。卡片预览与明确的“应用背景”按钮分离；显示“应用中／已应用”状态，应用中阻止重复请求。
- 每页最多 24 张。网格先显示固定尺寸占位，再分批加载缩略图；翻页替换当前页，不无限累积。随机翻页复用服务端返回的 seed，重新随机时清除 seed。
- 明确点击“搜索”或在搜索框按 Enter 才请求；输入文字、打开外观设置、应用启动不会自动联网。搜索与图片操作显示忙碌状态，支持取消。只读/退出中禁止修改设置。
- 下载选中图片成功、校验并写入缓存后才应用；失败保留当前背景。
- 界面标签、搜索占位符和失败提示支持即时切换中英文；错误保存结构化翻译键，显示时再翻译，不把底层英文错误直接拼进提示。切换语言只刷新文字，保留查询、筛选、当前页和已加载图片，不重新联网或解码。设置搜索同时匹配中英文背景图及颜色/纯色关键词。
- 服务端声明每分钟 45 次 API 请求。客户端使用更保守的本地速率预算，429 进入冷却，不自动密集重试。

## 模块与存储

| 模块 | 职责 |
| --- | --- |
| `src/wallpaper.rs` | 可序列化配置、查询、匿名 HTTP、响应验证、限流、受限解码及磁盘缓存 |
| `src/app/background.rs` | 独立背景视图、载入/切换生命周期、设置浏览器及后台任务 |
| `src/app/settings/appearance.rs` | 外观页入口与可搜索分组 |
| `src/store.rs` | `ui.background`，缺失字段兼容默认关闭 |
| `src/app/theme.rs` 与界面容器 | 只对大面积背景应用透明色，保留文字和功能性表面 |

背景设置只保存开关、强度和经校验的壁纸 ID，不将像素或远程响应放入 `state.json`。图片保存到 `Store::path()` 同目录的 `wallpapers/`，遵循 `CONDUIT_DATA_DIR` 和测试隔离。文件名由合法 ID 生成，使用完整临时文件加原子替换；最近的有限缓存支持恢复。当前已保存壁纸受保护，失败/取消的切换不删除它。缩略图仅驻留当前页，不写磁盘。

## 渲染与可读性

根界面保留主题底色，在其上绘制单个固定背景层，再绘制正常界面；背景与滚动内容分离，等比居中裁剪铺满。背景不接收鼠标、键盘或焦点。强度只作用于图片，不对应用根节点使用透明度。

背景层使用独立缓存实体；聊天输入、流式事件和滚动不会重新解码、重建图片或触发网络。窗口尺寸变化仅重新计算图片目标矩形，不重新采样。明暗主题沿用主题底色，背景强度默认较低并限制上限；侧栏、标题栏、设置页和详情容器使用统一的背景色辅助函数。输入框、菜单、代码块、Diff 高亮及终端内容保持可读的实色表面。

只有“有效图片从无到有/有到无”改变面板透明状态；单纯换图片或调整强度只更新独立背景实体。透明状态纳入缓存修订值，并显式通知相关缓存视图；不得为背景取消现有聊天/侧栏缓存。

浏览区作为独立实体嵌入设置页自身的滚动容器，按内容自然高度布局（GPUI 缓存视图要求固定尺寸，不用于整个浏览表单）；按实际设置块宽度调整 1–4 列，不再按窗口宽度猜测卡片宽度。只有列数发生变化才通知布局，不为每次测量触发刷新。

## 性能边界

| 资源 | 第一版预算 |
| --- | --- |
| 搜索结果 | 单页最多 24 张，JSON 最多 512 KiB |
| 缩略图 | 单张下载最多 1 MiB，输出最多 320 × 200；当前页像素约 5.9 MiB 上限 |
| 原图 | 压缩文件最多 20 MiB，解码前检查维度与最多 16 Mi 像素，拒绝超限资源 |
| 背景纹理 | 最多 3840 × 2160，CPU 像素约 31.7 MiB；GPU 副本、旧新图片切换和解码临时内存另计 |
| 解码并发 | 全局最多一个解码/缩放操作；不得在 GPUI 主线程执行 |
| 网络并发 | 一个浏览流程、一个背景载入流程；流程忙碌时禁止再启动，取消后等待在途操作收尾 |
| 磁盘缓存 | 最多 4 张、80 MiB，保留当前配置引用的图片；维护在后台执行 |
| 重绘 | 无轮播、无动画计时器、无实时模糊；背景图片和缩略图不参与每帧文件 I/O |

网络设置连接和总超时、响应体上限。缩略图单次总超时 8 秒，一页在 45 秒预算耗尽后不再发起请求；已在途的最后一次请求可在其超时前结束。API/原图总超时 25 秒。取消在操作间及响应读取中检查；不能宣称可抢占正在执行的同步解码。任务使用取消标记与请求身份，过期结果不得写回新页面或覆盖新选择。收起浏览器或离开外观页释放缩略图并取消浏览请求；关闭背景释放其像素引用，磁盘缓存用于下次启用。缩放采用有界整数采样，避免浮点滤镜中间图；替换/关闭时显式释放 GPUI 图集纹理。

图片按真实文件格式解析，限定静态 JPEG/PNG；响应中的原图和缩略图 URL 分别限定到 Wallhaven 官方 HTTPS 主机与路径，拒绝任意主机/重定向。文件大小限制与像素限制同时执行，不能只相信响应 JSON 或 Content-Length。

## 验证与验收

自动回归覆盖：旧配置默认关闭与非法参数收敛；查询编码、分类/SFW、分页 seed；非官方 URL/异常响应/超大图片拒绝；解码尺寸和通道正确；缓存裁剪保留当前图；取消和只读保护。缓存失效边界、聊天通知不重建背景及真实显存释放在性能验收中确认，不用精确渲染次数测试替代原生测量。

提交前执行 `scripts/check-core.ps1`。原生 Windows 验收使用隔离数据目录：中英文、明暗主题、窄窗口、搜索/翻页/选择/取消、重启离线恢复、下载失败保留旧背景、开关与关闭窗口。

性能验收比较同一构建中背景关闭/开启的长聊天滚动、流式输出和窗口缩放；记录完整帧耗时及进程 private bytes，不把测试渲染器当作 GPU 性能结果。重复切换并翻页后检查内存是否回落到稳定区间；稳定驻留应只包含当前背景与当前浏览页。未完成的真实 GPU、DPI 和长时间内存测量必须在交付中说明。
