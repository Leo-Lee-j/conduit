# Gemini CLI 接入

Conduit 通过独立的 `GeminiAdapter` 启动 `gemini --acp`，使用 ACP 1 的 JSON-RPC 标准输入/输出协议。兼容基线为 Gemini CLI 0.71.1。Windows 的 npm `gemini.cmd` 可直接使用，Node.js 需满足该 CLI 的版本要求（20 或以上）。

## 使用

1. 安装 Gemini CLI，在目标工作区的终端中完成原生认证，确认 CLI 可以正常对话。只设置 API Key 而没有选择原生认证方式，可能导致恢复会话失败；Conduit 不自动切换登录方式或写入认证设置。
2. 在「设置 → CLI」启用 Gemini CLI。支持 PATH 自动发现、手动指定 `gemini.cmd` 路径，或 `CONDUIT_GEMINI_PATH` 环境变量。
3. 新建会话选择 Gemini CLI，首次使用「CLI 默认」模型。连接后模型列表来自原生会话，所选模型通过 `session/set_model` 设置。
4. 后续消息沿同一原生 session ID 恢复。原生历史的重放不会重复添加到 Conduit；恢复失败会保留原会话并报错，不会静默新建。

安装版本、更新检查和已识别 npm 安装的原位更新使用现有 CLI 设置页。认证、模型可用性、代理、配额及服务访问条件由 Gemini CLI 和所选服务决定。

## 权限与配置

| 模式 | 行为 |
| --- | --- |
| 只读 | 原生策略拒绝所有工具，仅允许 `list_directory`、`read_file`、`grep_search`、`glob`；关闭 MCP 和扩展，额外审批仍拒绝。 |
| 工作区内修改 | 原生 default 模式，附加工具询问策略；审批选择原生 `allow_once` 或 `reject_once`，不会把单次批准变成永久授权。 |
| 完全访问 | 原生 yolo 模式，自动批准可用的单次工具请求；仍拒绝子代理、技能激活、写入记忆及计划模式切换工具。 |
| 标题等纯文本辅助任务 | 原生策略拒绝所有工具；运行中切换权限也不能解除限制。 |

这些是 CLI 工具权限，不是文件系统沙箱。经过批准的命令可能访问工作区外文件。普通聊天允许原生 MCP，工作区模式需要审批；只读与自动化任务关闭 MCP。所有模式使用 `--extensions none`，并拒绝子代理、技能激活、写入记忆和计划模式切换工具。

每轮通过 `--admin-policy` 加载独立的临时策略文件。原生配置、认证目录、HOME 和已有普通策略路径保持原样；运行时在完整进程树退出后删除临时策略。取消、启动失败和审批撤销均使用现有 ChatRuntime 生命周期。

Gemini 0.71.1 只加载具有管理员所有权的系统配置，普通临时系统配置会被忽略，因此本实现不使用系统配置覆盖，也不改变文件 ACL。已有 `C:/ProgramData/gemini-cli/policies/*.toml` 或任一配置层的 `adminPolicyPaths` 时，CLI 无法可靠叠加本轮策略，Conduit 会拒绝启动并提示使用原生 CLI。

启动前保守检查系统默认、用户、工作区和系统配置。若存在钩子条目、自定义工具发现/调用命令、MCP 总命令，或启用了后台代理、自动记忆、扩展热加载、Gemma 自动路由及 devtools，则拒绝启动。请先从原生配置移除相关条目或关闭对应实验功能；Conduit 不修改原配置。即使工作区当前不受信任或钩子另有禁用标记，也会检查已有条目，避免依赖运行时可能变化的合并结果。

## 当前范围

支持流式回复、思考片段、工具状态与文本/差异内容、计划事件、用量、模型选择、会话续接、工具审批和停止。模型的推理强度不提供手动档位。

暂未接入自定义模型服务/CC Switch 路由、原生命令、扩展编辑、子会话导航和 Gemini 终端历史批量导入。以 `/` 或 `$` 开头的消息会被拒绝，避免被 CLI 当作原生命令执行。音频/图片等二进制工具内容不会存入文本工具记录；不支持的反向 RPC 会收到明确错误。

## 验证

- 离线协议测试：新建/恢复、原生恢复响应不带 session ID、历史重放、模型/权限顺序、异常停止、审批选项 ID、取消、原生 JSONC 检查、企业策略冲突与策略文件清理。
- 进程夹具：保存门后启动，真实 stdio 交互、审批票据、取消、持有策略文件锁时的进程清理。
- 界面测试：引擎入口、原生模型目录持久化、模型切换、隐藏不支持的推理强度控件。
- 2026-11-25 使用临时安装的官方 0.71.1 包和隔离配置验证真实 ACP 握手、原生模型目录和权限模式；本地模拟模型用于验证工具执行边界，不调用付费模型。

可重复的原生验证：`python scripts/probe-gemini-policy.py --cli <安装目录>/node_modules/@google/gemini-cli/bundle/gemini.js`。脚本创建临时工作区和原生 home，使用本地 HTTP 模拟模型验证只读读取/拒绝写入、纯文本拒绝工具、恢复历史、工作区审批拒绝；不调用真实模型服务。

真实服务认证、付费模型调用和联网模型可用性仍需在目标账号环境中验收；离线测试不代表这些项目已完成。已有企业管理员策略暂不支持。

实现入口：`src/cli_adapter/gemini.rs`、`src/cli_adapter/gemini/config.rs`、`src/chat_runtime/gemini_tests.rs`。
