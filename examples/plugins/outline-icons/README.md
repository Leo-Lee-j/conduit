# Outline Icons

A local file icon plugin for Conduit. In **Settings → Plugins → Install from folder**, select this directory, then click **Use icons**.

Conduit copies the manifest and referenced SVGs into its plugin store. No build step or script runtime is required. Source files use warm orange, configuration uses amber, documentation uses blue, and folders have separate open/closed shapes.

[Icon theme format](../../../docs/plugins/icon-themes.md)

## 简体中文

在 **设置 → 插件 → 从文件夹安装** 中选择本目录，再点击 **使用图标**。安装不需要构建，也不执行脚本。源代码、配置和文档使用不同的图标与配色，文件夹提供展开和收起两种形状。
