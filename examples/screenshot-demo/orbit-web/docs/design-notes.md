# Orbit 设计笔记

让工作清晰，让界面安静。

## 视觉语言

| 元素 | 选择 | 目的 |
| --- | --- | --- |
| 背景 | 温润的灰白色 | 留出阅读空间 |
| 强调色 | 松绿色 | 标识当前操作与进度 |
| 字体 | 系统无衬线字体 | 离线可用，中文易读 |
| 卡片 | 细边框与轻微圆角 | 区分任务而不制造噪声 |

## 交互约定

1. 点击任务卡片查看详情，调整负责人和状态。
2. 搜索与成员筛选同时生效，任务总览保持项目全量统计。
3. 空结果明确提示；键盘操作保留可见焦点。
4. 手机端看板纵向排列，避免横向拖动阅读。
5. 用户内容以纯文本渲染，不插入 HTML。
