# Orbit · 把想法变成下一步

一个为 Conduit 宣传截图制作的虚构项目看板。团队、任务、日期和对话均为演示素材。

直接打开 `index.html`。无需安装依赖、配置账号或启动服务；没有网络请求。

- 四列任务看板与项目概览
- 关键词搜索、负责人筛选
- 新建任务、任务详情与状态调整
- 深浅主题、移动端布局
- 里程碑与项目文档

交互结果尽可能保存在浏览器本地存储；不支持存储的浏览器仍可在当前页面使用。
在 Conduit 中可以查看 `src/board.js`、`src/styles.css` 和 `docs/`，或打开 Git 面板审阅演示改动。

这些素材用于展示应用界面，预置对话并非真实模型运行记录。
